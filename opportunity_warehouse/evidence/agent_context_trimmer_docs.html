Agent Context Trimmer

v1.0.0 Production

1. Getting Started

Agent Context Trimmer audits and compresses AI instruction files (such as .cursorrules, AGENTS.md, and system_prompts) to eliminate token bloat and reduce AI API latency.

node bin/trimmer.js audit --dir ./my-project

2. CLI Reference

  • audit: Scans rules files and generates detailed savings breakdown without modifying files.
  • fix: Applies compression and prunes duplicate and verbose tokens.
  • --backup: Automatically generates timestamped .bak files before modifying.
  • --dry-run: Simulates fixes without writing to disk.
node bin/trimmer.js fix --dir ./my-project --backup

3. CI/CD Integration

Automate token bloat prevention on every Pull Request using GitHub Actions:

name: Context Bloat Audit
on: [pull_request]
jobs:
  audit:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: node bin/trimmer.js audit --dir . --fail-on-bloat

4. Offline Determinism & Privacy

Agent Context Trimmer runs 100% locally with zero external network requests, zero npm dependencies, and zero analytics.
