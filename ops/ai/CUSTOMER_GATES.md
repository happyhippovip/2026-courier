# Customer / External Gate Order

Internal safe preparation may proceed autonomously.

Recommended sequence:

1. software correctness,
2. Ledger / Guard / Motor truth,
3. exact-SHA Windows runtime readiness,
4. physical acceptance,
5. internal demo/video,
6. release/pilot readiness package,
7. explicit human authorization,
8. real customer contact / publication / public deployment / payment only when authorized.

Safe pre-gate work can include:
- validation,
- payload generation,
- internal demo material,
- checklists,
- dry-run representations,
- idempotency design,
- rollback plans,
- receipt schemas,
- verification logic,
- credential availability preflight without exposing secrets.

Never convert preparation into proof that the real external action happened.
