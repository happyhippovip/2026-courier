SOURCES_READ=Logical analysis of "Conditions requiring fallback to exact equality" in Behavioral Identity binding.
FACTS=The Behavioral Identity Envelope allows for variation within tested physical bounds. However, certain conditions render the envelope invalid, requiring a strict fallback to exact bitwise equality (exact candidate convergence, SHA equality).
NEW_FINDING=Fallback to exact equality is absolutely required when: (1) The cross-product of marginal boundaries (interaction effects) has not been physically tested in the Sensitivity Corpus; (2) Control-loop latency or chunking parameters deviate; (3) The detokenization/unnormalization code changes, as these non-linearly transform outputs; (4) The hardware/firmware hash diverges. In these cases, the "envelope" is undefined, so only exact byte-for-byte equality provides assurance.
