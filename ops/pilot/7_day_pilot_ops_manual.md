# Courier 7-Day Pilot Ops Manual

## Day 0: Setup & Intake
* Execute 3-Question Intake Script.
* Sign 1-Page ToS.
* Define Goal Contract.
* Verify local environment (Mac owner isolated from Windows Muse).

## Day 1: First Value
* Goal: Deliver first useful result in <= 30 minutes.
* Action: Execute Courier RUN1 (Physical).
* Measure: Time to First Value (TTFV).

## Day 2-3: Reliability & Restart
* Goal: Prove system handles interruption.
* Action: Induce failure, verify restart logic (no replay, context recovered).
* Metric: Human Interventions Per Goal (HIPG).

## Day 4-6: Full Autonomous Drain
* Goal: Run autonomous batches (12 units) without human intervention.
* Action: Courier self-routes and executes.
* Monitor: Resource bounds, process ownership.

## Day 7: Handoff & Review
* Goal: Deliver Continuity Audit.
* Action: Review workflow map, provide durable artifacts.
* Question: "Why will you return tomorrow?" (Assess repeat value).
