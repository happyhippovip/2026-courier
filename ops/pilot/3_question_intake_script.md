# Courier 3-Question Intake Script

1. **"What is the single most valuable artifact or decision brief you need generated, that you currently spend hours doing manually?"**
   *(Purpose: Identify the concrete First Value target that can be delivered in <= 30 mins)*

2. **"If this system stops working tomorrow, what specific data or context would you need durable access to in order to continue manually?"**
   *(Purpose: Define the Continuity Audit and ensure we don't lock them in)*

3. **"What are your absolute privacy boundaries for this task—what data cannot leave your local machine under any circumstances?"**
   *(Purpose: Configure the privacy boundary and telemetry settings before execution)*
