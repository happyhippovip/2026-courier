## Section order on `/`

1. Hero (file 02). Publish gate: always shippable — all lines phrased as mission, zero capability claims.
2. The problem (3 bullets, user words from plan §16): lost context, copy/paste between tools, re-explaining after session breaks, manual handoffs. SAFE: problem statements need no proof.
3. How it works — 4 steps, future tense (file 02). Publish gate: shippable now (labeled "How it will work").
4. What you see (pilot view: Arbeitet / Braucht dich / Fertig / Proof Card / Proof Level / Autonomy Grade — plan §14). Publish gate: shippable now ONLY with "pilot preview, not a shipped product" label.
5. Evidence, honestly (live status of Gates 1–4 in plain words + link to approach page). metrics row ships EMPTY: "No public metrics yet — first numbers after the physical proof." (Blueprint §5: never fabricated counters.)
6. Who it's for / who it's NOT for (pilot fit filter — feeds file 03).
7. Waitlist CTA → `/pilot#apply`.
8. Footer: contact, privacy summary link (file 04), "Built in the open — claims on this page are either goals or link to evidence."

## `/company` (concise per blueprint §10)

- Mission: one paragraph (external promise, plan §External promise).
- Why Courier exists: copy/paste exit — people lose work between AI tools and sessions; Courier's job is continuity with proof.
- Product philosophy: finish before expansion; no evidence → no claim; stop only at real boundaries.
- Roadmap (public, plain words): 1) trustworthy execution record → 2) reliable continuation → 3) zero-handoff demo → 4) restart-proof → 5) small paid pilots → 6) product shell. Each item labeled `done / in progress / next`, updated only on gate evidence.
- Contact: single email. FORBIDDEN on this page (register C13): team names/photos, offices, customers, investors, partners.

## Visual direction (blueprint, condensed for implementer)

Dark, calm, high-contrast; execution timeline + status blocks (RUNNING/WAITING/BLOCKED/UNKNOWN/DONE) as the recurring motif; clean system diagram on `/approach`. No fake dashboards, no stock AI imagery, no glowing gradients, no copied branding. Live status blocks may only show REAL gate states, never simulated activity.
