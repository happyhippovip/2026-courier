# Ideal Customer Profile (ICP) & Prospect Qualification Criteria

## Target Customer Definition
- **Company Profile:** Early-stage AI Agent Startups (Pre-Seed to Series A), Indie Hackers building autonomous workflows, DevTool labs.
- **Decision Maker:** Founder, CTO, Lead AI Engineer, or DevOps Platform Lead.
- **Primary Signal:** Public GitHub repository, X/Twitter posts, or blog posts discussing autonomous coding agents, multi-agent frameworks, or agent reliability challenges.

## Qualification Rules
- **Qualified:** Active Python/TypeScript agent codebase in development; team experiences silent stalls or concurrency issues; willingness to invest in crash-safety.
- **Disqualified:** Pure prompt-chaining wrappers with no local filesystem access; non-technical founders without an active code repository.
