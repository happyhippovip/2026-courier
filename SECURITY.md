# Security

Courier runs tasks on your own computer, so security reports matter.

- Please do not describe a vulnerability in a public issue.
- Use "Report a vulnerability" on the repository's Security tab if it is offered.
- If it is not offered, open an issue that only says you have a security report, without details, and a maintainer will arrange a private channel.

The project is pre-release. There are no supported versions yet; fixes go to `integration/v1`.
