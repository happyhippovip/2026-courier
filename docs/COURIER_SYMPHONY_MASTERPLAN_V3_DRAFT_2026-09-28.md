## Track 4 — PHYSICAL AI / ROBOTICS BEACON

Robotics is strategic upside, not a first-revenue dependency.

Courier does not build:
- a robot;
- a VLA;
- motion control;
- a simulator;
- a robot safety OS;
- a replacement fleet manager.

Courier aims to complement those systems with causal continuity, evidence and cross-worker work transfer.

### Public integration framing

- robot foundation model: decides/learns behavior;
- simulation/world model: trains and evaluates;
- safety architecture: constrains admissible physical action;
- fleet protocol: communicates and schedules;
- Courier: preserves work truth, evidence, causal progress and continuation across interruptions/workers.

### Public artifact 1 — Causal Handoff Benchmark

After Core Freeze + positive digital pilot, define an open benchmark for interrupted long-horizon work.

Metrics:
- duplicate-effect rate;
- unsafe continuation rate;
- stale-authority rejection;
- human interventions;
- evidence acquisition cost;
- time to resume;
- cross-worker/cross-embodiment continuation;
- provenance completeness.

Own the problem definition before expanding the product.

### Public artifact 2 — one reference integration

After Core Freeze + positive pilot:

build exactly one small reference integration with an accessible physical-AI stack, preferably Isaac/ROS 2 simulation.

Demonstrate:
- task starts;
- execution is interrupted;
- prior outcome is not blindly assumed;
- successor continues only from verified progress;
- stale executor cannot produce authoritative effects;
- proof record shows the chain.

Do not build broad robotics infrastructure yet.

## Track 5 — DATA / FAILURE COMPOUNDING

Every real failure should eventually become a reusable evaluation asset.

Publicly expose:
- incident identity;
- affected task boundary;
- version/runtime identity;
- evidence references;
- validation result.

Do not promise a universal failure-learning engine before it exists.

Long-term value:
real incidents can improve simulation/evaluation without requiring Courier to become the robot model trainer.

## Kill criteria

Reassess the strategic physical-AI thesis if:
- robot/fleet platforms natively solve vendor-neutral ambiguous-effect handoff end-to-end;
- the problem is rare or not economically painful in deployed fleets;
- buyers will not integrate a neutral continuity layer;
- public benchmark does not reveal meaningful differences between systems;
- the digital product cannot first prove the same continuity primitive.

Do not keep the thesis because it sounds futuristic.
