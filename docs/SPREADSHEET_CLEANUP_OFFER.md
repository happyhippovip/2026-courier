# Offer: Spreadsheet Cleanup & Transform

**For:** Small offices, local associations, and retail shops.
**Price:** €79 – €149 (fixed price, depending on size/complexity).
**Delivery:** Within 1 business day.

## The Pain We Solve
If you regularly deal with messy Excel files—lists of customers, inventory, or members—you know the pain of manual data entry. Phone numbers are formatted in five different ways, email addresses have accidental spaces, names are inconsistently capitalized, and duplicates are everywhere. Cleaning this by hand takes hours of your time and is prone to errors.

## What You Get
We take your messy `.xlsx` file and return a clean, normalized version.
- **Normalization:** We format all phone numbers, fix capitalization of names, trim accidental spaces, and standardize dates.
- **Merge & Deduplicate:** If you have multiple lists, we merge them and highlight or remove duplicates.
- **100% Data Integrity:** We use custom-built tooling that only modifies the exact cells that need cleaning. Everything else—your formulas, your layout, your formatting—remains **byte-for-byte identical**. 
- **Change Receipt:** You receive an exact, cell-by-cell receipt of what changed (e.g., `A4: " john doe " -> "John Doe"`), so you never have to guess if we accidentally deleted something important.

## How It Works
1. You send us the messy file and a brief description of what needs cleaning.
2. We run our automated, privacy-first tooling to clean the data. 
3. We send back the pristine file along with a transparent receipt of all changes.
4. If you aren't satisfied, you don't pay.

*We treat your data with absolute confidentiality. All processing is done locally, no data is sent to external cloud APIs, and the files are securely deleted after delivery.*
