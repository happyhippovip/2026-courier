Deine Chat-Organisation mit Emojis

Ein einfaches Ansichtspaket für Menschen, die verschiedene KI-Chats übersichtlich benennen möchten. Wähle eine Rolle aus, passe deinen Projektnamen an und kopiere Titel oder Startnachricht in deinen eigenen Chat.

🔒 Nur eine lokale Vorschau. Keine Anmeldung, keine API, keine Cloud-Anbindung und kein automatisches Speichern. Die Emojis benennen Chats – sie verbinden keine Apps, Geräte oder Projekte miteinander.

🚀 So startest du

  1. Eigenen Projektnamen oben eintragen.
  2. Auf eine Chat-Rolle mit Emoji tippen.
  3. Titel kopieren und deinen Chat entsprechend benennen.
  4. Startnachricht kopieren und im passenden Chat senden.
  5. Beim Chatwechsel die Übergabe kopieren, prüfen und im neuen Chat verwenden.

🛡️ Gut zu wissen

Alle Rollen sind Vorschläge. Für ein kleines Vorhaben reicht auch ein einziger Chat. „Prüfen“ ist keine automatische Kontrolle und „Sicherung“ erstellt keine echte Datensicherung. Bitte keine Passwörter, vertraulichen Dokumente oder privaten Daten öffentlich auf GitHub hochladen.

Diese Ansicht ist keine offizielle ChatGPT-Oberfläche. Sie kann auch ohne Internet als index.html im Browser geöffnet werden.
