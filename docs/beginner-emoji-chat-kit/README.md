# 🧩 Emoji-Chat-Organizer für Einsteiger

> 📱 🧭 💡 📚 🗓️ 🛠️ 🧪 💾  
> Eine **eigenständige, kostenlose HTML-Vorlage**, um KI-Chats mit klaren Namen und Emojis zu strukturieren. Ohne Login, ohne Server, ohne Programmierkenntnisse.

## ✨ Was du bekommst

- **Interaktive Vorschau** mit einer mobilen Chat-Übersicht und acht Beispielen: 🧭 Hauptchat, 💡 Ideen, 📚 Lernen, 🗓️ Planung, 🛠️ Umsetzung, 🧪 Prüfen, 💾 Übergabe und 📱 Unterwegs.
- **Eigenen Projektnamen eintragen** – zum Beispiel „Mein Garten“, „Meine Bewerbung“ oder „Deutsch lernen“.
- **Drei Kopierfunktionen** für jede Rolle: Chat-Titel, erste Nachricht und sichere Übergabe in einen neuen Chat.
- **Nur neutrale Beispieldaten:** keine echten Projektnamen, internen Pfade, echten Screenshots oder persönlichen Informationen.
- Alles in **einer HTML-Datei** (CSS und JavaScript sind eingebaut). Kein Konto und keine zusätzlichen Pakete nötig.

## 🚀 In drei Minuten loslegen

1. Öffne [index.html](index.html) und lade die Datei über GitHub herunter (in der Codeansicht z. B. **Raw / Download raw file**).
2. Öffne die heruntergeladene Datei **lokal in einem Browser**. Die GitHub-Codeansicht selbst ist **keine interaktive Vorschau**.
3. Gib deinen Projektnamen ein und wähle links eine Rolle aus.
4. Tippe **„📋 Titel kopieren“**, benenne damit einen neuen Chat in der KI-App deiner Wahl.
5. Tippe **„📋 Startnachricht kopieren“** und füge sie in diesen Chat ein.

**Ein Tipp für Anfänger:** Du musst nicht acht Chats erstellen. Ein Hauptchat reicht für kleine Projekte. Weitere Rollen nutzt du nur, wenn es wirklich übersichtlicher wird.

## 📋 Sofortvorlage ohne HTML

Du kannst auch einfach diesen Text kopieren:

    🧭 MEIN PROJEKT – HAUPTCHAT

    Du hilfst mir, mein Projekt übersichtlich zu organisieren.
    Erkläre alles einsteigerfreundlich.
    Trenne Ziele, Ideen, echte Ergebnisse und offene Fragen.
    Erfinde keine erledigten Arbeiten.
    Beende deine Antwort mit dem nächsten kleinen Schritt.
    Frage bei fehlenden wichtigen Informationen einmal gezielt nach.

**Chatwechsel / Übergabe:**

    💾 ÜBERGABE IN EINEN NEUEN CHAT

    Fasse ausschließlich unser wirklich besprochenes Projekt zusammen.
    1. Ziel
    2. Vereinbarungen
    3. Nachweislich erledigt
    4. Offen oder unklar
    5. Nächster Schritt

    Bitte keine vertraulichen Informationen oder erfundenen Erfolge ergänzen.
    Ich prüfe die Zusammenfassung und kopiere sie selbst weiter.

## 🔒 Datenschutz und wichtige Grenzen

- Das Paket sendet **keine Daten** an Server oder Anbieter. Es benutzt **keine externen Schriftarten, Tracker, Bibliotheken oder API-Aufrufe**. Die angepassten Werte existieren nur während die Seite offen ist; **kein automatisches Speichern**.
- Ein Emoji wie 💾 **erstellt keine Datensicherung**. Ein Titel wie 🧪 Prüfen **beweist keinen unabhängigen Test**.
- Chat-Namen **verbinden nicht** verschiedene Chats, Geräte, KI-Modelle oder Konten. Eine Übergabe muss gegebenenfalls manuell kopiert werden.
- Die HTML-Vorlage führt **keine KI-Aufträge** aus, öffnet keine anderen Apps und verursacht selbst keine Modellkosten. Die Nutzung eines KI-Dienstes unterliegt dessen jeweiligem Tarif.
- Keine Zugangsdaten, Gesundheits-/Familieninformationen, privaten Projekte oder andere vertrauliche Inhalte in öffentliche GitHub-Repositories hochladen.
- Die Gestaltung ist eine **eigene Beispielansicht**, kein Nachbau oder offizielles Produkt von ChatGPT oder einem anderen KI-Anbieter.

## 🛠️ Anpassung

Du brauchst für die Grundfunktion **nichts zu programmieren**. Zum Teilen reicht die einzelne Datei [index.html](index.html).

Wer HTML/JavaScript kennt, kann die Liste der Rollen im Array \`roles\` innerhalb von \`index.html\` anpassen. Die Standardbeispiele sind absichtlich harmlos und offline. Für Änderungen an der Vorlage niemals vertrauliche Daten verwenden.

## ✅ Qualitätscheck für dieses Paket

Die Vorlage wurde auf folgende Punkte ausgerichtet:

- Eigenständige Datei und keine externen Abhängigkeiten.
- Keine echten Projektdaten oder abfotografierten privaten Chats.
- Copy-Buttons für Titel, Prompt und Übergabe.
- Nur Textausgabe aus Eingaben; keine HTML-Injektion durch den Projektnamen.
- Tastaturbedienbarkeit, Beschriftungen und mobile Darstellung.
- Keine falsche Behauptung einer automatischen Chat-Synchronisierung.

**Hinweis:** Die Browserdarstellung und das Kopieren können je nach Gerät abweichen. Falls ein Kopierbutton nicht funktioniert, den sichtbaren Text manuell markieren.
