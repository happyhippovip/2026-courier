## 2661–2670 — Pilot-Failure-Abbruch festlegen

`scripts/check_pilot_readiness.py` hat nur geprüft, ob vier Dateien da sind, und ist dann mit Exit 0 stehen geblieben. Die negative Signalregel aus `ops/ai/PILOT_METRICS_AND_SIGNAL_SPEC.md` (HIPG > 0, NDR < 100, Verifier außer Scope, Daemon ohne Recovery) hatte keine Funktion.

Rot:

```text
ImportError: cannot import name 'pilot_failure_aborts'
from 'scripts.check_pilot_readiness'
```

`pilot_failure_aborts` hält an, wenn `hipg` > 0, `ndr_pct` < 100, ein Zähler fehlt oder kein Ganzzahler ist, `verifier_accepted_out_of_scope` wahr ist oder `daemon_failed_to_recover` wahr ist. `hipg` 0 und `ndr_pct` 100 brechen nicht ab. Derselbe Record liefert zweimal dasselbe. `check_readiness` bleibt der Datei-Check; die alten zwei Tests bleiben grün.

## 2671–2675 — Erfolgsbelege einem Kunden zeigen
